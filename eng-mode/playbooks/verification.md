# Verification

State: Test. Node: `Verify actual behavior`.

1. Run every required acceptance check on the current artifact in the relevant environment. Apply validation.
2. Exercise the behavior the goal claims. Run the regression check, nearby behavior checks, and the affected project checks. Apply testing.
3. Re-run affected checks after integration and after the last relevant change.
4. Reproduce decisive worker evidence yourself. A worker's summary is not verification.
5. Record every check in the evidence table. Apply evidence collection.

For documentation, check instructions, paths, examples, and claims against the real artifact. For a skill, check discovery and invocation, then exercise representative tasks. Text validation alone does not prove agent behavior.
