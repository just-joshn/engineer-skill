# Investigation

Deliver an answer, not an unrequested implementation.

1. State the question and what observation would settle it.
2. Inspect the actual system, source, records, or artifact. Separate known facts from assumptions.
3. Form a small set of competing explanations. Choose the cheapest experiment that distinguishes them.
4. Run the experiment and preserve the observed evidence.
5. Update the explanation. Repeat only when another experiment can reduce a material uncertainty.
6. Report the supported answer, rejected explanations, limits, and the smallest justified next step.

Delegate independent questions with separate evidence sources. Retain synthesis and the final conclusion.

If a prototype is needed, isolate it and avoid production writes. A successful prototype proves only the behavior and environment it exercised. Move to a change playbook only when the user authorized changes.
