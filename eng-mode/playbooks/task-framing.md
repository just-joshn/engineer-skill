# Task framing

State: Plan. Node: `Goal, constraints, and acceptance checks`.

1. Restate the goal and the smallest change that meets it. Read [goal framing](../skills/goal-framing.md).
2. Inspect the workspace, its instructions, current changes, and existing checks before you edit.
3. Record the user's constraints, the host's limits, and the non-goals. Read [constraint analysis](../skills/constraint-analysis.md).
4. Define observable acceptance checks, including the failure and boundary cases the request implies. Read [acceptance criteria](../skills/acceptance-criteria.md).
5. Record the authorized endpoint. The default is `Handoff`, with a local artifact and evidence. Commit, publish, open a pull request, merge, deploy, delete data, or contact another person only when the user authorized that action.
