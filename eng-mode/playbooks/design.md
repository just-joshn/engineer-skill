# Design

State: Design. Node: `Choose playbook; investigate and design`.

1. Name the data shapes, state transitions, invariants, interfaces, and boundaries. Read [system design](../skills/system-design.md).
2. Identify every affected caller and any migration the change requires.
3. Choose the smallest design that satisfies the goal.
4. Define shared interfaces and integration order before any work is split.
5. Record the design and any acceptance checks it adds.
