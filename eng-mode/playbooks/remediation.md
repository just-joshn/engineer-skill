# Remediation

State: Maintain. Node: `Report limits and remaining work`.

1. For each blocker, describe the smallest remedy. That is a fix, an access grant, a missing input, or an authorization. Read [remaining-work reporting](../skills/remaining-work-reporting.md).
2. Say whether the remedy is inside the current scope and authority.
3. Do not apply the remedy in this run. List it as remaining work.
