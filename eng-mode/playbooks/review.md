# Review

State: Test. Node: `Verify actual behavior`.

Assess the requested scope. Do not modify it unless the user asked for fixes.

1. Establish intent, acceptance checks, base revision, and the exact artifact under review.
2. Inspect the whole relevant change and its surrounding contracts.
3. Prioritize correctness, safety, regressions, missing behavior checks, and unnecessary complexity.
4. Probe each suspected defect with a test, reproduction, or concrete source trace.
5. Write each finding with its location, affected behavior, evidence, and impact. Apply review.
6. Separate new defects from pre-existing issues. Drop preferences that do not affect the goal or an established project rule.

Delegate distinct risk questions when useful. Verify each returned finding before adopting it.
